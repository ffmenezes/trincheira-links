Página de download das tabelas fiscais brasileiras em CSV (abre no Excel) e JSON: NCM com alíquotas de IPI e II, TIPI, TEC, CEST, CFOP, CNAE, o de-para CEST↔NCM e a lista de ocupações permitidas ao MEI. São oito datasets, todos gratuitos.

Os dados vêm das fontes oficiais — Siscomex, Receita Federal, MDIC/Gecex, CONFAZ e IBGE — e são regerados a cada atualização delas, o que resolve o problema clássico de achar a planilha certa de NCM e descobrir que é de dois anos atrás. Para quem vai integrar em sistema em vez de baixar arquivo, o site também expõe uma API REST gratuita em JSON (com OpenAPI) e páginas de consulta código a código.
