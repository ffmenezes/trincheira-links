TTT (Terminal Text Tool) se vende como "a IDE que mora no seu terminal" e mira quem usa VS Code, Zed ou Sublime mas não quer decorar atalho de Vim. É uma TUI que se comporta como GUI: barra de menus, diálogos, clique direito, multi-cursor, busca no workspace com ripgrep e temas com preview ao vivo.

Já vem com LSP (completions, diagnósticos, rename, referências, formatação), terminal embutido com abas e true color, e Git completo: stage, commit, push, diff inline, blame e revisão de PR do GitHub. Workspaces com várias pastas ficam salvos em arquivos `.ttt`.

Código no [GitHub](https://github.com/eugenioenko/ttt) (MIT, ~1,1 mil estrelas). Instala com `go install github.com/eugenioenko/ttt/cmd/ttt@latest`, flake do Nix ou script de instalação pra Linux. Projeto novo (criado em janeiro de 2026), então espere arestas.
